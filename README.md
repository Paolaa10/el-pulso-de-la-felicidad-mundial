# El pulso de la felicidad mundial

## Integrante
Nahomi Paola Álvarez de la Cruz

## Descripción
Proyecto individual para desarrollar un dashboard interactivo que permita comparar la felicidad de distintos países y explorar su relación con factores económicos y sociales. Se utilizará el conjunto de datos World Happiness 2015–2024. El dashboard incluirá indicadores, gráficos y un mapa mundial.
